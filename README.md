# 레레 디스코드 봇

## Python 배포

호스팅 설정에서 Python 3.10 이상을 선택하고 시작 파일을 `main.py`로 지정하세요. 필요한 패키지는 `requirements.txt`에 있습니다. `.env` 파일에 저장한 값도 자동으로 읽습니다.

다음 환경변수를 호스팅 서비스의 비밀 설정에 등록해야 합니다.

- `DISCORD_BOT_TOKEN`: Discord 개발자 포털에서 발급한 봇 토큰
- `GOOGLE_SHEETS_API_KEY`: Google Sheets API 키

봇에는 서버(길드)와 애플리케이션 명령 사용 권한이 필요합니다. Google 스프레드시트는 링크 공개 상태여야 합니다. 캐릭터 등록 정보는 `BOT_DATA_DIR`에 저장됩니다. 별도 설정이 없으면 프로젝트 폴더의 `data` 폴더를 사용합니다. 호스팅 서비스에서 디스크가 재시작 후에도 유지되는지 확인하고, 필요하면 `BOT_DATA_DIR`을 영속 저장 경로로 지정하세요.

## 명령어

`/관찰`, `/응원`, `/선택`, `/기능판정`, `/임의판정`, `/주사위`, `/비밀주사위`, `/운세`, `/캐릭터등록`, `/캐릭터목록`, `/캐릭터리셋`

Python 실행 환경에서 시작 파일로 `main.py`를 실행하면 됩니다.

# 레레 디스코드 봇

## Python 배포

호스팅 설정에서 Python 3.10 이상을 선택하고 시작 파일을 `main.py`로 지정하세요. 필요한 패키지는 `requirements.txt`에 있습니다. `.env` 파일에 저장한 값도 자동으로 읽습니다.

다음 환경변수를 호스팅 서비스의 비밀 설정에 등록해야 합니다.

- `DISCORD_BOT_TOKEN`: Discord 개발자 포털에서 발급한 봇 토큰
- `GOOGLE_SHEETS_API_KEY`: Google Sheets API 키

봇에는 서버(길드)와 애플리케이션 명령 사용 권한이 필요합니다. Google 스프레드시트는 링크 공개 상태여야 합니다. 캐릭터 등록 정보는 `BOT_DATA_DIR`에 저장됩니다. 별도 설정이 없으면 프로젝트 폴더의 `data` 폴더를 사용합니다. 호스팅 서비스에서 디스크가 재시작 후에도 유지되는지 확인하고, 필요하면 `BOT_DATA_DIR`을 영속 저장 경로로 지정하세요.

## 명령어

`/관찰`, `/응원`, `/선택`, `/기능판정`, `/임의판정`, `/주사위`, `/비밀주사위`, `/운세`, `/캐릭터등록`, `/캐릭터목록`, `/캐릭터리셋`, `/모의전투`

모의전투는 채널마다 하나의 모집을 열고, 등록된 캐릭터를 최대 8명까지 참가시킬 수 있습니다.

- `/모의전투`: 캐릭터끼리 싸우는 대련을 모집합니다. 최소 2명이 필요합니다. 레이드를 비워 두면 대련으로 모집합니다.
- `/모의전투 레이드:연습용 허수아비`: 참가자들이 같은 팀으로 허수아비를 공격합니다. 혼자서도 시작할 수 있습니다. 허수아비는 HP가 없으며 공격·회피·반격을 하지 않습니다. 모집자가 **훈련 종료**를 누르면 총 피해와 캐릭터별 누적 피해를 보여줍니다. 모든 참가자가 탈락해도 종료됩니다.
- `/모의전투 레이드:실험키메라`: 시작 시 능력치를 무작위로 정하는 몬스터입니다. 2~3명 기준이며, HP는 2명일 때 25~50, 3명일 때 40~65입니다. 1명은 10~35이고 이후 인원이 한 명 늘 때마다 HP 범위가 15씩 높아집니다. 민첩 25~85, 근접전 30~75, 회피 10~50이며 전투 도중에는 다시 뽑지 않습니다. 장갑 1은 공격 한 발마다, 반격·지속 피해·자해에도 적용하고 최종 피해는 최소 0입니다.
- 모집창의 **참여** 버튼: 본인에게만 보이는 선택창에서 등록한 캐릭터를 고르면 참가합니다. 캐릭터가 많으면 이전·다음 페이지로 이동합니다. 다른 캐릭터를 추가하려면 참여 버튼을 다시 누릅니다. 선택창은 5분 후 만료되며 참여 버튼으로 다시 열 수 있습니다. 모집자가 **전투 시작**을 누르면 진행됩니다.

키메라는 발톱 행동 두 차례 후 도약을 예고하는 순서를 반복합니다. 발톱은 근거리에서 1d6 피해를 주며, 멀면 민첩 판정으로 한 단계 접근합니다. 도약은 지목된 캐릭터의 다음 차례가 끝난 뒤 발동해 1d8 피해를 주고 근거리가 됩니다. 예고 후 해당 캐릭터가 키메라에게서 거리를 넓혔다면 덮치기에 패널티 +1을 적용합니다. 회피·반격도 가능합니다. HP가 절반 이하인 자기 차례에는 한 번만 공격 대신 1d6을 회복하고, 다음 자기 차례까지 반격하지 않습니다. 평소 근접 공격에는 25% 확률로 반격하고 그 외에는 회피하며, 몬스터에게는 기절·중상 판정을 하지 않습니다. 피해에 DB는 추가하지 않습니다. 키메라의 HP가 0이면 참가자 팀의 승리, 참가자가 전부 탈락하면 실패합니다.

전투 순서는 민첩 내림차순이며, 민첩이 같으면 1d100 성공 단계를 비교하고 단계가 같은 캐릭터끼리 다시 굴립니다. 시트의 무기·기능치를 읽어 공격, 방어, 피해와 체력을 계산하며 거리, 엄폐, 중상, 충격·지속 상태를 적용합니다. 굴림 기록은 최근 6개까지 표시합니다. 전투 상태는 메모리에만 보관되므로 봇이 재시작되면 진행 중인 전투도 사라집니다.

사격 무기를 선택하면 발수 선택창에서 **재장전**할 수 있습니다. 재장전은 턴을 소모하며, 탄약을 무기가 처음 전투에 추가됐을 때 읽은 수까지 채웁니다. 0발인 총과 일부만 사용한 총 모두 가능하지만, 고장 난 무기·투척무기·처음부터 탄약 수가 없거나 0인 무기는 제외합니다. 예비 탄약은 별도로 차감하지 않고, 시트 값도 변경하지 않습니다.

Python 실행 환경에서 시작 파일로 `main.py`를 실행하면 됩니다.

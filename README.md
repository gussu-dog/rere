# 레레 디스코드 봇

## Python 배포

호스팅 설정에서 Python 3.10 이상을 선택하고 시작 파일을 `main.py`로 지정하세요. 필요한 패키지는 `requirements.txt`에 있습니다. `.env` 파일에 저장한 값도 자동으로 읽습니다.

다음 환경변수를 호스팅 서비스의 비밀 설정에 등록해야 합니다.

- `DISCORD_BOT_TOKEN`: Discord 개발자 포털에서 발급한 봇 토큰
- `GOOGLE_SHEETS_API_KEY`: Google Sheets API 키

봇에는 서버(길드)와 애플리케이션 명령 사용 권한이 필요합니다. Google 스프레드시트는 링크 공개 상태여야 합니다. 캐릭터 등록 정보는 `BOT_DATA_DIR`에 저장됩니다. 별도 설정이 없으면 프로젝트 폴더의 `data` 폴더를 사용합니다. 호스팅 서비스에서 디스크가 재시작 후에도 유지되는지 확인하고, 필요하면 `BOT_DATA_DIR`을 영속 저장 경로로 지정하세요.

## 명령어

`/관찰`, `/응원`, `/선택`, `/기능판정`, `/임의판정`, `/주사위`, `/비밀주사위`, `/운세`, `/캐릭터등록`, `/캐릭터목록`, `/캐릭터리셋`, `/모의전투`

모의전투는 채널마다 하나의 모집을 열고, 등록된 캐릭터를 최대 8명까지 참가시킬 수 있습니다.

- `/모의전투 구분:모집 종류:대련`: 캐릭터끼리 싸우는 대련입니다. 최소 2명이 필요합니다. 종류를 생략하면 대련으로 모집합니다.
- `/모의전투 구분:모집 종류:레이드 상대:연습용 허수아비`: 참가자들이 같은 팀으로 허수아비를 공격합니다. 혼자서도 시작할 수 있고, 상대를 생략하면 허수아비가 선택됩니다. 허수아비는 HP가 없으며 공격·회피·반격을 하지 않습니다. 모집자가 **훈련 종료**를 누르면 총 피해와 캐릭터별 누적 피해를 보여줍니다. 모든 참가자가 탈락해도 종료됩니다.
- `/모의전투 구분:참여 캐릭터:…`: 등록된 캐릭터를 선택해 모집에 참가합니다. 모집자가 **전투 시작**을 누르면 진행됩니다. 종류와 상대는 비워 둡니다.

전투 순서는 민첩 내림차순이며, 민첩이 같으면 1d100 성공 단계를 비교하고 단계가 같은 캐릭터끼리 다시 굴립니다. 시트의 무기·기능치를 읽어 공격, 방어, 피해와 체력을 계산하며 거리, 엄폐, 중상, 충격·지속 상태를 적용합니다. 굴림 기록은 최근 6개까지 표시합니다. 전투 상태는 메모리에만 보관되므로 봇이 재시작되면 진행 중인 전투도 사라집니다.

Python 실행 환경에서 시작 파일로 `main.py`를 실행하면 됩니다.
